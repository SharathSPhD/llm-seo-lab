### Deterministic offline ledger

[`scripts/seed-use-cases.mjs`](../../../scripts/seed-use-cases.mjs) loads the
configs, imports the per-substrate adapters from
`plugin/scripts/adapters/<substrate>.ts` directly via Node 22's
`--experimental-strip-types`, and writes a deterministic `state.jsonl`
that mirrors what the matching Supabase rows would contain after the same
flow had been driven via the dashboard.

| Use case | Stages walked offline | Events written |
|---|---|---|
| `u1-technektar-dev` | DRAFT → RECOMMENDED | 7 |
| `u2-technektar-substack-context-window` | DRAFT → RECOMMENDED → APPLIED → REPUBLISHED → MEASURING → MEASURED → ANALYZED (3 engine observations, verdict `improved`) | 17 |
| `u3-youtube-fM2hpqPx8zg` | DRAFT → RECOMMENDED → APPLIED | 9 |

U2 (Substack) is the canonical end-to-end exemplar. The three engine
observations are realistic (not stubs) and each captures the per-engine
behaviour we expect from the charter principles:

- **ChatGPT** cited at position 1 — the `inverted-retrieval-target`
  (answer-first lede) was quoted nearly verbatim.
- **Perplexity** cited at position 2 — `cross-engine-intermediary`
  (canonical-paper attribution block) put Substack second after the
  Liu et al. "Lost in the Middle" paper.
- **Google AIO** did not cite — the recorded recommendation for iteration
  2 is to widen the canonical-paper anchor block and / or to add a
  Google-friendly FAQPage on a companion `technektar.dev` page (the
  next-iteration hint baked into the analysis row).

The verdict (`improved`, 2/3 engines cite) and the per-engine delta /
attractor metrics block in the analysis row mean U2 satisfies the
verification gate "≥3 measurement rows from at least 2 different engines"
and "non-stub `analyses` row that cites at least one TRIZ principle and
one attractor-flow metric from the use case's history".
