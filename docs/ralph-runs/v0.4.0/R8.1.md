## Locked decisions captured by the docs

The plan, PRD, and spec all converge on the following decisions, each
of which traces back to a verbatim user request earlier in the session:

1. **Skip Supabase / Vercel entirely.** No parallel mode. The v0.3.0
   git tag is the Supabase reference.
2. **Cloudflare Pages + D1** is the hosted backend.
3. **GitHub OAuth** replaces Supabase magic-link.
4. **JSONL is canonical, SQLite is the cache, D1 is the hosted mirror.**
5. **Local Claude Code CLI** continues to drive the inventive layer;
   the hosted dashboard cannot speak to Claude directly. The
   `pending_actions` table bridges them.
6. **`AuthUser` interface preserved bit-for-bit.** Only the `source`
   discriminator changes from `"local" | "supabase"` to
   `"local" | "github"`.
7. **`LLM_SEO_LAB_AUTH=local` shim preserved.**
8. **Plugin manifests bump to 0.4.0** and gain a sixth `/pull:sync`
   command.
